# Nail Room Vysotskaya — сайт ногтевой студии

Многостраничный статический сайт для ногтевой студии Nail Room Vysotskaya (Минск, Прилукская ул., 60). Чистый HTML, CSS и JavaScript: без сборки и зависимостей.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: рейтинг, услуги, темы отзывов |
| `services.html` | Услуги и цены |
| `about.html` | О студии |
| `contacts.html` | Адрес, телефон, мессенджеры, карта, форма записи в WhatsApp |

## Структура

```
.
├── index.html, services.html, about.html, contacts.html
├── style.css      # стили и цвета
├── main.js        # меню, форма записи, плавное появление
├── favicon.ico, favicon-32.png, favicon-192.png, apple-touch-icon.png
└── images/        # фото студии
```

## Возможности

- Адаптивная вёрстка, мобильное меню
- Плавное появление блоков при прокрутке (отключается при «уменьшить движение»)
- Форма записи открывает WhatsApp с готовым сообщением
- Карта Яндекса, favicon

## Запуск локально

```bash
python3 -m http.server 8000
```

Сайт откроется на http://localhost:8000.

## Публикация на GitHub Pages

1. Загрузите содержимое папки в корень репозитория.
2. **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через пару минут сайт появится по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.

## Что где править

- **Цены** — `services.html`. Сейчас указаны только маникюр с покрытием (85 Br) и классический маникюр (от 60 Br). Для остальных замените `<span class="pr ask">цену уточняйте</span>` на `<span class="pr">70 Br</span>`.
- **Телефон и мессенджеры** — в футере каждой страницы, в `contacts.html` и в `main.js` (ссылка `wa.me/...`).
- **Время работы** — на сайте не указано, потому что на Яндекс Картах оно не опубликовано. Добавьте строку в `contacts.html`.
- **Цвета** — переменные в начале `style.css` (`--pink`, `--berry`, `--blush`, `--ink`).
- **Шрифты** — Bodoni Moda и Josefin Sans (Google Fonts).

## Источники данных

Адрес, телефон, соцсети, рейтинг, цены и список услуг взяты с карточки студии на Яндекс Картах. Фото предоставлены для проекта.
